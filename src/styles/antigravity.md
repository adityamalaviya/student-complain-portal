# Styles Module — `src/styles`

## Purpose
Defines core design tokens and global styles for the CampusVoice portal.

## Token Reference
- **Brand Colors:** Royal collegiate blue `#1D4ED8`, hover `#1E40AF`, accent `#2563EB`.
- **Canvas:** Minimalist slate canvas `#F8FAFC`, crisp pure white `#FFFFFF` surface.
- **Dark Mode:** Canvas `#030712`, surface `#0B132B`.
- **Status Indicators:** Open (amber `#D97706`), In Progress (blue `#2563EB`), Resolved (emerald `#059669`).
