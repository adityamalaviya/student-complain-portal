# Utils Module — `src/lib/utils`

## Purpose
Pure utility functions for class combining (`cn.ts`), canonical 6-department & `[7:9]` enrollment mapping (`department.ts`), 5-day SLA calculation (`delay.ts`), Indian mobile number input normalization (`phone.ts`), and explicit frontend state machines, onboarding eligibility, attachment validation, and route-guard resolution (`stateMachines.ts`).
